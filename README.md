# Учет расходников развлекательного клуба

Веб-приложение для удобного отслеживания и заказа расходных материалов по филиалам.

## Возможности
- 📱 Мобильный адаптивный интерфейс
- 🏬 Разделение по филиалам (Калинина, МГ, Ленина, Планета)
- 🔴 Статусы запасов: `есть`, `заказать`, `заказано`, `нет`
- 🔍 Мгновенный поиск по расходникам
- 📋 Отдельный экран сводки для закупки

## Как запустить на GitHub Pages
1. Загрузите `index.html` и `README.md` в ваш репозиторий на GitHub.
2. Перейдите в **Settings -> Pages**.
3. В поле **Source** выберите ветку `main` (или `master`) и нажмите **Save**.
4. Через минуту приложение будет доступно по вашей публичной ссылке!
